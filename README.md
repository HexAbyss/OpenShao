# Assets

Screenshots and other material that is not part of the OpenShao source.
The pull request and issue descriptions link to these files.

- `captures/cheat-menu/`: screenshots of the cheat menu, Save Game and Full Health at Statue (pull request #31).
- `captures/hd-textures/`: screenshots of texture packs. `menu-*` and `gameplay-*` compare the High and Low quality settings of the same pack, and `priority-*` show how the order of two packs on the Mods page decides which one wins a texture. `developer-*` are the Developer mode switch and page, `mods-page-details-lorem.png` and `launcher-quality-*` the Mods page with the details of a pack and the quality setting. The pack in `menu-*` and `gameplay-*` is [Mortal Kombat Shaolin Monks (HD Texture by Matasiete)](https://gbatemp.net/threads/dragonmortal-kombat-shaolin-monks-hd-texture-by-matasiete-dragon.673436/); it is not part of this repository.
- `captures/modkit/`: screenshots of the OpenShao ModKit, the tool that makes texture packs: its pages, the progress of an extraction and of a compilation, and its start screen.
